# skill-distill

Форк идеи «сильный проход → скилл для дешёвой модели». Текст скилла и проверки написаны заново и не повторяют чужой промпт: чужой скилл сюда не копируется и в `~/.claude/skills` не ставится.

Студент этого прохода — вёрстка трёх заметок Drafts. Модели: `codex/gpt-6-luna`, `codex/gpt-6.1-terra`, `kimi-for-coding-oauth/k3`, `zai/glm-5.3-flash`.

Запуск студента, когда в каталоге есть исходные `board.md`, `steps.md`, `herdr.md`:

```bash
python3 grade.py --help
```

`grade.py` проверяет уже разобранный ответ. Живые заметки Drafts скрипт не трогает.
