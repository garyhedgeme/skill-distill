# Дистилляция прохода

Сильная модель уже сделала задачу. Дешёвая должна повторить её по скиллу, без чужого промпта из сети: текст скилла пишешь сам, чужой файл скилла в контекст не кладёшь.

## Шаги

1. Назови студента: `omp -p`, точный id модели, чистый каталог.
2. Напиши скилл студента: решения, ловушки, проверка в конце каждого шага. В скилл не входит готовый результат и нет команды, которая его печатает.
3. Запусти студента с исходным запросом и этим скиллом. Выключи его чужие скиллы, правила и файлы контекста (`--no-skills --no-context-files --no-rules`).
4. Проверь ответ проверками, которые эталон тоже проходит. Проверка, которую эталон не проходит, сломана — поправь проверку, не ответ.
5. На первом провале поменяй скилл в этом месте и запусти снова. Один удачный запуск ничего не доказывает: три запуска одной версии, прежде чем считать её годной.

Готово, когда оператор видит эталон и лучший ответ студента рядом и принимает скилл. До этого скилл в общее дерево скиллов не ставь.
