# Вёрстка заметки

Меняешь только раскладку текста. Факты, имена и формулировки остаются. Сеть не открывай. Новых адресов не добавляй. Заметку не пересказывай: верни её целиком.

Делай шаги по порядку. Следующий шаг не начинает работу предыдущего заново.

## 1. Первая строка

Первая строка видна в списке как название, без обработки markdown.

- Короткая фраза без символов рамки — не трогай.
- Заметка начинается с рамки `┌`: поставь одну строку-название по смыслу шапки таблицы, не длиннее 60 знаков, без `|`, `#` и символов рамки. Рамку разбирай на шаге 2.
- Первая строка — целое предложение длиннее 80 знаков: вставь перед ним короткую строку из имён продуктов, которые в этом предложении уже есть. Само предложение оставь следующим абзацем. Решётку не ставь.

Готово, когда первая строка короче 80 знаков и в ней нет `┌`, `│`, `└`, `#`.

## 2. Рамка-таблица

Удали линии, собранные из `┌ ├ └ ┬ ┴ ┤ ─`. Строку с `│` разрежь по `│` и обрежь края. Несколько таких строк подряд до следующей границы — одна строка таблицы: непустые куски одной клетки склей одним пробелом. Запиши markdown-таблицу: строка шапки, строка `| --- | --- |`, затем данные.

Готово, когда символов `┌ │ └ ├ ┤ ┬ ┴` не осталось вне блоков между тройными кавычками.

## 3. Расползшаяся таблица

Участок начинается со строки `| ----- |`. Клетка — непустая строка, в которой есть что-то кроме `|`, `-` и пробела. Строка, которая начинается с `#`, кончает участок и в таблицу не входит. Первая клетка `Возможность` значит три клетки в строке, иначе две. Собери markdown-таблицу. Строки `| ----- |` удали.

Готово, когда текста `| ----- |` не осталось.

## 4. Схема и пример конфигурации

Серия строк с отступом в четыре пробела, где есть `│`, `▼` или строка `execution_backends:`, — блок. Сними ровно четыре пробела, убери пустые строки по краям, оберни в тройные кавычки. Отступ, который остался внутри, сохрани.

Готово, когда схема со стрелками и пример `execution_backends` стоят в таких блоках, а не просто с отступом.

## 5. Заголовки, ссылки, мусор

- `## **текст**` и `### **текст**` — сними `**`, решётки оставь.
- Строка между пустыми, короче 50 знаков, без точки, не кончается на `:`, не список и не строка таблицы — сделай из неё `## `.
- Удали строку, если она целиком равна одному из: `10`, `8`, `GitHub`, `GitHub+1`, `Orca Docs`, `The agent development environment+1`.
- Ссылку на хост `images.openai.com` замени пунктом `- ` и текстом подписи. Подпись `(@) on X` удали вместе со ссылкой.
- С остальных ссылок сними суффикс `?utm_source=chatgpt.com`.
- Вне блоков с тройными кавычками замени пробел-дефис-дефис-пробел на ` — `. Написание `--file` и `--kind` не меняй.
- Если внутри слова между буквами стоит один `=`, удали его.
- Перед строкой `- `, которая идёт сразу после абзаца, вставь пустую строку.
- В предложении, которое начинается с «Его ставит», команду `npx ...` возьми в обратные кавычки.

Готово, когда этих строк-мусора нет, а предложение про установку читается с командой в кавычках.

## 6. Сдача

Перед ответом пройди herdr.md построчно. Удали строку, если после обрезки пробелов она равна `The agent development environment+1`, `GitHub+1`, `Orca Docs`, `GitHub`, `10` или `8`. В каждой оставшейся строке, где есть `](http`, вырежи хвост от `](` до конца строки. Серию соседних строк, где есть `│` или `▼`, оберни в ```, если она ещё не внутри такого блока. То же со строкой `execution_backends:` и строками под ней до пустой строки. После этого в заметке не должно остаться `images.openai.com`, а `│` встречается только внутри ```.

Три заметки, каждую целиком, без пояснения вокруг:

<<<FILE board.md>>>
текст заметки
<<<END>>>

<<<FILE steps.md>>>
текст заметки
<<<END>>>

<<<FILE herdr.md>>>
текст заметки
<<<END>>>

Заметку целиком в тройные кавычки не оборачивай.
